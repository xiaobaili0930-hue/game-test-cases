# 蛋蛋龙 · 浮岛日记

参考用户截图及四段录屏制作的浏览器单人原型。所有龙、蛋、场景使用 SVG/CSS 原创绘制，无需外部素材、运行依赖或构建。数值和部分玩法为演示设计，不是原版完整复刻。

## 运行

解压后直接双击 `index.html`，或在本目录运行：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

通过浏览器访问服务器 8000 端口。发布、GitHub 推送和在线托管需另行操作。

## 玩法

- 固定两排共 **8 个孵化位**。点击空草台或「龙蛋背包」放蛋，等待 20～90 秒，点击发光龙蛋孵化。
- 六种龙可查看状态、喂食、摸摸或确认送去远游；家园上限 8 只。不同品种有不同角、翼或尾巴装饰。
- 每只小龙每分钟带回 5 金币，最多累计 120 分钟，点击「收取礼物」领取。出生前的时间不会产生收益。
- 首次收录一种龙额外获得 15 经验，普通孵化获得 10 经验，喂食获得 3 经验，每 30 经验升一级。
- 场景栏切换已拥有的家园；商店购买龙蛋、食物、魔法时钟和场景，部分按等级解锁。魔法时钟使一颗正在孵化的蛋立即就绪，需在背包使用。
- 图鉴分森月族、元素族，支持分页，未发现种类显示问号。
- 底部为**本地演示好友**，点击卡片串门、点击便便打扫，获得 5 金币与 2 经验，每个好友每日奖励一次。点击「我的家」返回。自己的家园每 90 秒可打扫一次。
- 每日礼物提供 150 金币及 3 食物。

## 存档与限制

继续使用 `dragon-island-v1` localStorage，兼容第一版的龙、货币、蛋、孵化时间和图鉴记录，并补充新字段。好友奖励与每日礼物按设备本地日期计算。进度仅在当前浏览器和访问来源下保存；更换浏览器、清除数据或从文件访问切换到服务器可能无法继续原存档。

不含真实好友、账号、联网、战斗、支付及云存档。图鉴分类、价格、解锁等级和时间均为原型设计，录屏尚不能证实全部原版规则。参考分析见 `docs/video-reference.md`。

## 开发验证

复用当前仓库，无需额外 Git worktree。语法检查：`node --check game.js`。

已安装 Playwright 和 Chromium 的开发环境可先启动上述服务器，然后运行：

```sh
node tests/browser.cjs
```

可通过 `GAME_URL`、`CHROMIUM_PATH` 环境变量选择测试服务地址和浏览器路径。浏览器检查覆盖旧存档迁移、8 个孵化位、好友访问与打扫奖励限制、孵化与发现奖励、喂食、商店分页/等级锁、时钟、场景购买/切换/存档、图鉴分类/分页及手机布局；截图输出至 `artifacts/`。测试使用独立浏览器上下文，不会改变日常浏览器存档。
