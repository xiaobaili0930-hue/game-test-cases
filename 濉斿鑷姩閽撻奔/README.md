# 塔塔冒险队 自动钓鱼（微信 Mac 客户端）

纯屏幕层：截屏 → HSV 颜色识别状态 → pyautogui 点击。不碰游戏进程/协议。

## 游戏流程（2026-10-22 连拍实测）
1. 待机：底部绿色钓竿按钮 → 点一下抛竿
2. 等鱼约 5 秒，按钮变灰
3. 咬钩：紫色「就是现在!拉钩!!」框（约 0.5 秒窗口）+ 按钮变紫 → 立刻点
4. 小游戏：横条上红白浮标以约 185px/s 来回跑，进黄区时点按钮（「酷!」「好棒!」），黄区每次命中后随机换位，2~3 次命中结束
5. 结算弹窗（刷新个人纪录 / 恭喜获得）→ 点掉回待机

## 最省事的用法（给同事也是这个）
1. 把整个文件夹拷过去（不含 .venv/debug）。
2. 双击 `安装并启动.command`：首次自动建虚拟环境、装依赖（1~3 分钟），然后打开浏览器控制台 http://127.0.0.1:8766。
   - 若提示「无法打开，来自身份不明的开发者」：右键→打开；或终端执行 `xattr -dr com.apple.quarantine 文件夹路径`。
   - 需要 Python 3.9+（系统自带 /usr/bin/python3 即可；首次可能弹 Xcode 命令行工具安装）。
3. 页面「环境检测」里按提示开权限：屏幕录制 + 辅助功能都勾上**运行它的那个应用**（双击 .command = 终端 Terminal），勾完重启终端再双击一次。
4. 微信打开塔塔冒险队，页面检测到窗口后设轮数，点「开始」。急停：鼠标甩屏幕左上角。

## 一次性准备（命令行方式）
1. 系统设置 → 隐私与安全性 → **屏幕录制** 和 **辅助功能** 勾上跑脚本的终端。
2. 游戏窗口放在 **内置屏**（monitor 1），**不要全屏**，位置/大小和校准时一致（窗口左上角约 (560,55)），别被其它窗口盖住。

```bash
cd ~/claude/塔塔自动钓鱼
PY=~/claude/venv/bin/python
```

## 跑
```bash
$PY fish.py --reset-window        # 先把窗口恢复到校准时的位置/大小再跑（可与下面参数组合）
$PY fish.py --restore-cursor      # 每次点完把光标移回原位（每次借用光标约 100ms），可边跑边用鼠标
$PY fish.py --dry --duration 20   # 只识别不点击，看状态切换是否正确
$PY fish.py                       # 正式跑；鼠标甩到屏幕左上角 = 急停；Ctrl+C 退出
$PY fish.py --rounds 30           # 钓 30 轮自动停
$PY fish.py --replay debug/burst  # 用连拍帧离线回放验证状态机
```

## 重新校准（窗口挪过 / 识别不对）
```bash
$PY calib.py --burst 180 --interval 0.25   # 连拍 3 分钟到 debug/burst/，期间手动玩几轮
```
然后用 debug/burst/ 的帧重新量 config.json 里的坐标和 HSV（量法见会话记录；calib.py 的交互模式是旧版「滑块+能量条」口径，已不适用）。

## config.json 关键字段
| 字段 | 含义 |
|---|---|
| grab | 每帧只截这块区域 (x,y,w,h)，覆盖拉钩框+横条+按钮 |
| button | 唯一点击位（抛竿/拉钩/命中/关弹窗都点它） |
| ring_* | 按钮环 HSV：绿=待机 灰=等鱼 亮紫=咬钩或小游戏 暗紫=弹窗 |
| bite_pts / bite_hsv | 拉钩框紫色采样点 |
| bar_roi / track_hsv / zone_hsv / bobber_hsv | 横条区域及轨道蓝/黄区/浮标红 |
| lead_ms | 提前量，老点晚了 ↑ |
| zone_margin | 黄区两端留白比例 |
| click_cooldown_ms | 两次点击最小间隔 |
| popup_click_s | 弹窗状态下点击间隔 |

## 已知局限
- 微信小游戏只认真实光标位置的点击：CGEventPostToPid / 带窗口号字段 / AnnotatedSessionTap 投递合成事件全部无效（10-22 实测），所以做不到完全不占鼠标，只能 `--restore-cursor` 借用后归还。
- 高奖励模式黄区会缩到 ~23px 与浮标同宽，浮标压上去时黄色被盖住；fish.py 用「黄区记忆」沿用上次完整看到的位置（命中后清零）。
- 启动时按窗口标题「塔塔冒险队」自动定位，位置随意；尺寸变了按等比换算（宽高不等比或缩放超 1.5 倍拒跑）；`--reset-window` 可直接复位到校准时的 453x848。
- 结算弹窗靠点按钮位关闭，若某种弹窗点这里关不掉会卡在 POPUP 反复点，Ctrl+C 看日志。
